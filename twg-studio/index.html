AdMob IDs

These go into the game and the Android manifest. Paste them, or pull them straight out of your account below.

Never tap your own live ads on an unregistered phone. AdMob reads that as invalid traffic and suspending an account is not something you can appeal quickly. Add your device to AD_TEST_DEVICES in the game HTML first — the SDK prints the exact id to logcat on the first ad request.

Connect AdMob

One-time setup. After this, one click pulls your App ID and all three ad unit IDs out of your account and writes them everywhere.

You need an OAuth client first (free, 3 minutes, once ever):
1. Create a Google Cloud project
2. Enable the AdMob API
3. OAuth consent screen → External → add your own Gmail under Test users
4. Credentials → Create credentials → OAuth client ID → Web application
5. Authorised redirect URI: http://localhost:4747/oauth/callback
6. Copy the client ID and secret into the two boxes below.
