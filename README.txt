THE WHATEVER GAME — Windows
===========================
1. Keep TheWhateverGame.exe and resources.neu in the SAME folder.
2. Double-click TheWhateverGame.exe. That's it.

Notes:
- Requires Microsoft Edge WebView2 (preinstalled on Windows 10/11).
  If the window is blank, install it: https://developer.microsoft.com/microsoft-edge/webview2/
- Windows SmartScreen may warn because the app is unsigned:
  click "More info" -> "Run anyway".
- Controls: mouse or keyboard (Space/WASD/arrows, V = VS mode, L = leaderboard,
  M = mute, G = test mode, N = skip mode while testing).
